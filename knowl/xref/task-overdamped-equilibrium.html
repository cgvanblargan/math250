Task 3.4.1.b. Does the Mass Pass Through Equilibrium?

Will the mass ever pass through the equilibrium position \(x = 0\text{?}\)
🔗
Hint.
Set \(x(t) = 0\) and solve for \(t\text{.}\) Remember that only \(t \geq 0\) is physically meaningful.
🔗
🔗
Solution.
Full solution
We solve \(4e^{-2t} - 10e^{-t} = 0\text{.}\) Since \(e^{-t} \neq 0\text{,}\) divide both sides by \(e^{-t}\text{:}\)
\begin{equation*} 4e^{-t} - 10 = 0 \implies e^{-t} = \frac{10}{4} = \frac{5}{2} \implies t = -\ln\!\left(\tfrac{5}{2}\right) \approx -0.92. \end{equation*}
Since \(t \lt 0\text{,}\) this is not a valid time. The mass never passes through equilibrium for \(t \geq 0\text{.}\)
