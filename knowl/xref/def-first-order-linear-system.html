Definition 5.2.1. First-Order Linear System.

A first-order linear system with two functions \(x_1(t)\) and \(x_2(t)\) can be written in the form:
\begin{align*} x_1' \amp= p_{11}(t)x_1 + p_{12}(t)x_2 + f_1(t)\\ x_2' \amp= p_{21}(t)x_1 + p_{22}(t)x_2 + f_2(t) \end{align*}
where \(x_1(t)\) and \(x_2(t)\) are functions that solve both ODEs simultaneously.
