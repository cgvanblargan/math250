Example 4.1.2. A Basic Inverse Laplace Transform.

Compute \(\mathcal{L}^{-1}\!\left\{\dfrac{1}{s+5}\right\}\text{.}\)
🔗
We look for a row in the table whose \(F(s)\) column matches \(\dfrac{1}{s+5}\text{.}\) This fits Formula B with \(a = -5\text{:}\)
\begin{gather*} \mathcal{L}\{e^{at}\} = \frac{1}{s-a} \quad \Longrightarrow \quad \mathcal{L}\{e^{-5t}\} = \frac{1}{\underbrace{s-(-5)}_{s+5}} = \frac{1}{s+5}. \end{gather*}
Reading backwards:
\begin{equation*} \mathcal{L}^{-1}\!\left\{\frac{1}{s+5}\right\} = e^{-5t}. \end{equation*}
