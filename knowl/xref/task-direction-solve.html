Task 3.4.1.c. Find All Direction Changes.

Now find all times \(t \geq 0\) at which the mass changes direction. Recall \(x(t) = e^{-2t}(2\cos(t) + 2\sin(t))\text{.}\)
🔗
Hint.
Step 1. Compute \(x'(t)\) using the product rule.
🔗
Step 2. Solve \(x'(t) = 0\text{.}\) Since \(e^{-2t} \neq 0\text{,}\) you can factor it out and solve what remains.
🔗
🔗
Solution.
Since \(x'(t) = 0\) at every direction change, we compute \(x'(t)\) and solve.
🔗
Solution 1. Step 1: Compute \(x'(t)\)
Using the product rule:
\begin{align*} x'(t) \amp= -2e^{-2t}(2\cos(t) + 2\sin(t)) + e^{-2t}(-2\sin(t) + 2\cos(t))\\ \amp= e^{-2t}\bigl(-4\cos(t) - 4\sin(t) - 2\sin(t) + 2\cos(t)\bigr)\\ \amp= e^{-2t}(-2\cos(t) - 6\sin(t)). \end{align*}
🔗
🔗
So \(x'(t) = e^{-2t}(-2\cos(t) - 6\sin(t))\text{.}\) Now we set this equal to zero and solve.
🔗
Solution 2. Step 2: Solve \(x'(t) = 0\)
Since \(e^{-2t} \neq 0\text{,}\) we need:
\begin{align*} -2\cos(t) - 6\sin(t) \amp= 0\\ -6\sin(t) \amp= 2\cos(t)\\ \frac{\sin(t)}{\cos(t)} \amp= -\frac{2}{6}\\ \tan(t) \amp= -\frac{1}{3}. \end{align*}
By part 1 of Remark 3.4.1 with \(A = -1/3\text{,}\) every solution has the form:
\begin{equation*} t = \arctan\!\left(-\tfrac{1}{3}\right) + n\pi, \quad n = 0, \pm 1, \pm 2, \ldots \end{equation*}
By part 2 of Remark 3.4.1, since \(A = -1/3 \lt 0\text{,}\) the valid solutions with \(t \geq 0\) start at \(n = 1\text{.}\)
🔗
🔗
So starting at \(n = 1\) ensures every value of \(t\) is nonnegative, and the mass changes direction at:
\begin{equation*} t = \arctan\!\left(-\tfrac{1}{3}\right) + n\pi, \quad n = 1, 2, 3, \ldots \end{equation*}
