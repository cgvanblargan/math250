    Section 4.1.4 More Inverse Laplace Transform Examples

    On this page, we continue taking inverse Laplace transforms. These problems are just a bit harder and more involved than the previous ones, so pay attention to the various tricks used throughout!
    🔗
    Use the Laplace transform table below as a reference throughout this page.
    🔗
    As a warmup, consider \(F(s) = \dfrac{13}{3s+21}\text{.}\) This should match Formula B, \(\mathcal{L}\{e^{at}\} = \dfrac{1}{s-a}\text{,}\) but we need a 1 in the numerator and the denominator in the form \(s - a\text{.}\) Factor the 3 out of the denominator:
    \begin{equation*} \frac{\overbrace{13}^{\text{needs to be }1}}{3s+21} = \frac{13}{\underbrace{3(s+7)}_{\text{factor out }3}} = \frac{13}{3} \cdot \frac{1}{s-(-7)}. \end{equation*}
    Now it matches Formula B with \(a = -7\text{.}\)
    🔗

    Checkpoint 4.1.2.

    Finish computing \(\mathcal{L}^{-1}\!\left\{\dfrac{13}{3s+21}\right\}\) using the rewrite from above.
    🔗
    • \(\dfrac{13}{3}e^{-7t}\)
    • Correct! After factoring, \(\frac{13}{3} \cdot \frac{1}{s+7}\) matches Formula B with \(a = -7\text{,}\) giving \(\frac{13}{3}e^{-7t}\text{.}\)
    • \(13e^{-7t}\)
    • Don’t forget the \(\frac{1}{3}\) from factoring the 3 out of the denominator.
    • \(\dfrac{13}{3}e^{7t}\)
    • Check the sign of \(a\text{.}\) Since \(s + 7 = s - (-7)\text{,}\) we have \(a = -7\text{,}\) giving \(e^{-7t}\) not \(e^{7t}\text{.}\)
    • \(\dfrac{13}{21}e^{-7t}\)
    • The constant comes from factoring 3 out of the denominator, giving \(\frac{13}{3}\text{,}\) not \(\frac{13}{21}\text{.}\)
    🔗
    In the next example, it becomes slightly more complicated because there are two terms in the numerator. How should we deal with this?
    🔗

    Example 4.1.3. Inverse Laplace with Two Terms.

    Find \(\mathcal{L}^{-1}\!\left\{\dfrac{13-3s}{s^2+9}\right\}\text{.}\)
    🔗
    Hint.
    • Split the fraction over the numerator and apply linearity to get two separate inverse transforms.
      🔗
      🔗
    • Both terms have denominator \(s^2 + 9 = s^2 + 3^2\text{,}\) so \(a = 3\text{.}\) Check the table to identify which formula each term matches.
      🔗
      🔗
    🔗
    🔗
    Solution.
    Split over the numerator and apply linearity:
    \begin{align*} \mathcal{L}^{-1}\!\left\{\frac{13-3s}{s^2+9}\right\} \amp= 13\,\mathcal{L}^{-1}\!\left\{\frac{1}{s^2+9}\right\} - 3\,\mathcal{L}^{-1}\!\left\{\frac{s}{s^2+9}\right\}. \end{align*}
    Both terms have denominator \(s^2 + 9 = s^2 + 3^2\text{,}\) so both match Formula D or Formula E; the difference is what’s in the numerator:
    \begin{gather*} \frac{\overbrace{1}^{\text{constant} \Rightarrow \text{D}}}{s^2+3^2} \qquad \text{vs} \qquad \frac{\overbrace{s}^{s \Rightarrow \text{E}}}{s^2+3^2}. \end{gather*}
    The first term needs a 3 on top to match Formula D, so rewrite:
    \begin{align*} \amp= \frac{13}{3}\,\mathcal{L}^{-1}\!\left\{\frac{\overbrace{3}^{a}}{s^2+3^2}\right\} - 3\,\mathcal{L}^{-1}\!\left\{\frac{s}{s^2+3^2}\right\}\\ \amp= \frac{13}{3}\sin(3t) - 3\cos(3t). \end{align*}
    🔗
    🔗
    🔗
    In the following activity, there are also two terms in the numerator. It is somewhat similar to the last example, so make sure you look at that before this activity! We will break down the first few steps before solving it in full.
    🔗

    Activity 4.1.1. Find \(\mathcal{L}^{-1}\!\left\{\dfrac{1+s}{s^3}\right\}\).

    Work through the following steps.
    🔗

    (a) Step 1: Simplify and Split.

    Split \(\dfrac{1+s}{s^3}\) over the numerator and simplify each term. Which of the following is correct?
    🔗
    • \(\dfrac{1}{s^3} + \dfrac{1}{s^2}\)
    • Correct! Splitting gives \(\frac{1}{s^3} + \frac{s}{s^3}\text{,}\) and \(\frac{s}{s^3} = \frac{1}{s^2}\text{.}\)
    • \(\dfrac{1}{s^3} + \dfrac{1}{s^3}\)
    • The second term is \(\frac{s}{s^3}\text{,}\) not \(\frac{1}{s^3}\text{.}\) Simplify by canceling one factor of \(s\text{.}\)
    • \(\dfrac{1}{s^3} + s\)
    • \(\frac{s}{s^3} = \frac{1}{s^2}\text{,}\) not \(s\text{.}\)
    • \(\dfrac{1}{s^2} + \dfrac{1}{s^2}\)
    • Only the second term simplifies to \(\frac{1}{s^2}\text{.}\) The first term is \(\frac{1}{s^3}\text{.}\)
    🔗

    (b) Step 2: Identify the Table Rows.

    Looking at the table above 4.1.1, which formula applies to each of the two terms \(\dfrac{1}{s^3}\) and \(\dfrac{1}{s^2}\text{?}\)
    🔗
    • Both match Formula C, \(\mathcal{L}\{t^n\} = \dfrac{n!}{s^{n+1}}\text{,}\) with different values of \(n\text{.}\)
    • Correct! Both terms are of the form \(\frac{1}{s^{n+1}}\text{,}\) just with different \(n\text{.}\)
    • \(\dfrac{1}{s^3}\) matches Formula A and \(\dfrac{1}{s^2}\) matches Formula C.
    • Formula A is just \(\frac{1}{s}\text{,}\) which corresponds to \(n = 0\) in Formula C. Both of your terms have higher powers of \(s\text{,}\) so both match Formula C.
    • Both match Formula B, \(\mathcal{L}\{e^{at}\} = \dfrac{1}{s-a}\text{.}\)
    • Formula B has a linear denominator \(s - a\text{.}\) Here the denominators are powers of \(s\text{,}\) which match Formula C instead.
    • \(\dfrac{1}{s^3}\) matches Formula C and \(\dfrac{1}{s^2}\) matches Formula H.
    • Formula H involves \(e^{at}\text{,}\) which doesn’t appear here. Both terms match Formula C with different values of \(n\text{.}\)
    🔗

    (c) Step 3: Compute the Inverse Transform.

    Using Formula C, compute \(\mathcal{L}^{-1}\!\left\{\dfrac{1+s}{s^3}\right\}\text{.}\)
    🔗
    Hint.
    Match each term to Formula C by identifying \(n\text{:}\)
    • \(\dfrac{1}{s^3} = \dfrac{1}{s^{2+1}}\text{,}\) so \(n = 2\) and \(n! = 2\text{.}\)
      🔗
      🔗
    • \(\dfrac{1}{s^2} = \dfrac{1}{s^{1+1}}\text{,}\) so \(n = 1\) and \(n! = 1\text{.}\)
      🔗
      🔗
    Rewrite each term to get \(n!\) in the numerator before applying the table.
    🔗
    🔗
    Solution. Full Solution
    Starting from the beginning:
    \begin{align*} \frac{1+s}{s^3} \amp= \frac{1}{s^3} + \frac{s}{s^3} = \frac{1}{s^3} + \frac{1}{s^2}. \end{align*}
    Both terms match Formula C, \(\mathcal{L}\{t^n\} = \dfrac{n!}{s^{n+1}}\text{,}\) with \(n = 2\) and \(n = 1\) respectively. Rewriting to get \(n!\) on top:
    \begin{align*} \mathcal{L}^{-1}\!\left\{\frac{1}{s^3} + \frac{1}{s^2}\right\} \amp= \mathcal{L}^{-1}\!\left\{\frac{1}{2!}\cdot\frac{2!}{s^{3}}\right\} + \mathcal{L}^{-1}\!\left\{\frac{1}{1!}\cdot\frac{1!}{s^{2}}\right\}\\ \amp= \frac{1}{2}\,\mathcal{L}^{-1}\!\left\{\frac{2!}{s^{2+1}}\right\} + \mathcal{L}^{-1}\!\left\{\frac{1!}{s^{1+1}}\right\}\\ \amp= \frac{1}{2}t^2 + t. \end{align*}
    🔗
    🔗
    🔗
    🔗

    Key Takeaways.

    • Factor first: if the denominator has a leading coefficient, factor it out before matching the table.
      🔗
      🔗
    • Split over the numerator: a sum in the numerator can always be split into separate fractions, then handle each one independently.
      🔗
      🔗
    • Identify n carefully for Formula C: match the power of \(s\) in the denominator to \(s^{n+1}\text{,}\) then rewrite to get \(n!\) on top.
      🔗
      🔗
