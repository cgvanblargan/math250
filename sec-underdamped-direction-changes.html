    Section 3.4.1 Analyzing Underdamped Motion

    Before we begin the main content of this page, let’s review a couple of facts about trig equations that we’ll need later on. We’ll start with these prerequisites, and then come back to them when we work through Task 3.4.1.c.
    🔗

    Remark 3.4.1. Prerequisite: Solving \(\tan(\theta) = A\).

    1. Solving \(\tan(\theta) = A\text{.}\) Taking arctan of both sides gives one solution, \(\theta = \arctan(A)\text{,}\) but this is not the only one. Since \(\tan\) has period \(\pi\text{,}\) shifting any solution by \(\pi\) gives another solution. The complete solution set is:
      \begin{equation*} \theta = \arctan(A) + n\pi, \quad n = 0, \pm 1, \pm 2, \ldots \end{equation*}
      🔗

      Why does this give all solutions?

      Because \(\tan(\theta)\) has period \(\pi\text{,}\) the equation \(\tan(\theta) = A\) is satisfied by exactly one value of \(\theta\) in each interval of length \(\pi\text{.}\) The function \(\arctan\) is the inverse of \(\tan\) restricted to \((-\pi/2,\, \pi/2)\text{,}\) so \(\arctan(A)\) picks out the unique solution in that interval. Every other solution is obtained by adding an integer multiple of \(\pi\text{,}\) covering all intervals.
      🔗
      🔗
      🔗
    2. Restricting to \(t \geq 0\text{.}\) Continuing from part 1 with \(\tan(t) = A\text{,}\) we have \(t = \arctan(A) + n\pi\text{,}\) and we want to know which values of \(n\) give \(t \geq 0\text{.}\) There are two cases:
      1. \(A \geq 0\text{:}\) valid solutions start at \(n = 0\text{.}\)
        🔗
        🔗
      2. \(A \lt 0\text{:}\) valid solutions start at \(n = 1\text{.}\)
        🔗
        🔗
      🔗

      Why n = 0 or n = 1? (can skim).

      The key fact is that \(\arctan(A) \in (-\pi/2, \pi/2)\) always has the same sign as \(A\text{.}\)
      🔗
      Case 1: \(A \geq 0\text{.}\) Then \(\arctan(A) \geq 0\text{,}\) so \(\arctan(A) + n\pi \geq 0\) for all \(n \geq 0\text{.}\) Since negative \(n\) would give \(\arctan(A) + n\pi \lt 0\text{,}\) the valid solutions start at \(n = 0\text{:}\) \(n = 0, 1, 2, \ldots\)
      🔗
      Case 2: \(A \lt 0\text{.}\) Then \(\arctan(A) \in (-\pi/2, 0)\text{,}\) so \(n = 0\) gives a negative value of \(t\) (not valid). But since \(|\arctan(A)| \lt \pi/2 \lt \pi\text{,}\) adding one full period gives \(\arctan(A) + \pi > 0\text{.}\) Valid solutions: \(n = 1, 2, 3, \ldots\)
      🔗
      🔗
      🔗
    🔗
    🔗
    Okay now let’s turn to the underdamped case, where the mass oscillates with decaying amplitude.
    🔗

    Summary: Underdamped Case of \(mx'' + cx' + kx = 0\).

    Case Discriminant and roots Crossings of \(x=0\) \(\displaystyle\lim_{t\to\infty} x(t)\)
    Underdamped (smaller \(c\)) \(0 \lt c^2 \lt 4km\) (complex roots with nonzero real part) Infinitely many \(0\)
    🔗
    To make things concrete, let’s fix a specific underdamped system and work with it for the rest of this page.
    🔗
    Consider the underdamped system with \(m = 1\text{,}\) \(c = 4\text{,}\) \(k = 5\text{,}\) \(x(0) = 2\text{,}\) \(x'(0) = -2\text{.}\) Substituting these parameters gives the IVP:
    \begin{equation*} x'' + 4x' + 5x = 0, \quad x(0) = 2,\quad x'(0) = -2. \end{equation*}
    The solution to this IVP is:
    \begin{equation*} x(t) = e^{-2t}(2\cos(t) + 2\sin(t)). \end{equation*}
    🔗
    Solution. Work: Solution to the IVP (can skim)
    With \(m=1\text{,}\) \(c=4\text{,}\) \(k=5\) the characteristic equation is \(r^2 + 4r + 5 = 0\text{.}\) The discriminant is \(D = 16 - 20 = -4 \lt 0\text{,}\) confirming the system is underdamped. By the quadratic formula:
    \begin{equation*} r = \frac{-4 \pm \sqrt{-4}}{2} = -2 \pm i. \end{equation*}
    So \(\alpha = -2\) and \(\omega = 1\text{,}\) giving general solution:
    \begin{equation*} x(t) = e^{-2t}(c_1\cos(t) + c_2\sin(t)). \end{equation*}
    Applying \(x(0) = 2\text{:}\) \(c_1 = 2\text{.}\) Differentiating and applying \(x'(0) = -2\text{:}\)
    \begin{equation*} x'(0) = -2c_1 + c_2 = -2 \implies c_2 = -2 + 2(2) = 2. \end{equation*}
    So \(x(t) = e^{-2t}(2\cos(t) + 2\sin(t))\text{.}\)
    🔗
    🔗
    Now let’s think about what this solution actually looks like in motion, and in particular, when the mass changes direction.
    🔗

    Exploration 3.4.1. When Does the Mass Change Direction?

    Note: to make the direction changes clearly visible, we use a slower decay rate here (\(\alpha = -0.15\) instead of \(-2\)). The qualitative behavior is the same.
    🔗
    🔗

    (b) Connect to Calculus.

    Based on your observations above, which equation corresponds exactly to the mass changing direction?
    🔗
    • \(x'(t) = 0\)
    • Correct! Direction changes occur exactly at critical points of \(x(t)\text{,}\) where \(x'(t) = 0\text{.}\) Note that for underdamped systems, every critical point is a direction change (no saddle points), since the solution oscillates. \(\checkmark\)
    • \(x(t) = 0\)
    • \(x(t) = 0\) means the mass is at the equilibrium position, not that it is changing direction. The mass can pass through equilibrium while still moving.
    • \(x''(t) = 0\)
    • \(x''(t) = 0\) corresponds to inflection points of \(x(t)\text{,}\) not direction changes.
    • \(x'(t) = x(t)\)
    • This equation has no direct physical meaning in this context.
    🔗

    (c) Find All Direction Changes.

    Now find all times \(t \geq 0\) at which the mass changes direction. Recall \(x(t) = e^{-2t}(2\cos(t) + 2\sin(t))\text{.}\)
    🔗
    Hint.
    Step 1. Compute \(x'(t)\) using the product rule.
    🔗
    Step 2. Solve \(x'(t) = 0\text{.}\) Since \(e^{-2t} \neq 0\text{,}\) you can factor it out and solve what remains.
    🔗
    🔗
    Solution.
    Since \(x'(t) = 0\) at every direction change, we compute \(x'(t)\) and solve.
    🔗
    Solution 1. Step 1: Compute \(x'(t)\)
    Using the product rule:
    \begin{align*} x'(t) \amp= -2e^{-2t}(2\cos(t) + 2\sin(t)) + e^{-2t}(-2\sin(t) + 2\cos(t))\\ \amp= e^{-2t}\bigl(-4\cos(t) - 4\sin(t) - 2\sin(t) + 2\cos(t)\bigr)\\ \amp= e^{-2t}(-2\cos(t) - 6\sin(t)). \end{align*}
    🔗
    🔗
    So \(x'(t) = e^{-2t}(-2\cos(t) - 6\sin(t))\text{.}\) Now we set this equal to zero and solve.
    🔗
    Solution 2. Step 2: Solve \(x'(t) = 0\)
    Since \(e^{-2t} \neq 0\text{,}\) we need:
    \begin{align*} -2\cos(t) - 6\sin(t) \amp= 0\\ -6\sin(t) \amp= 2\cos(t)\\ \frac{\sin(t)}{\cos(t)} \amp= -\frac{2}{6}\\ \tan(t) \amp= -\frac{1}{3}. \end{align*}
    By part 1 of Remark 3.4.1 with \(A = -1/3\text{,}\) every solution has the form:
    \begin{equation*} t = \arctan\!\left(-\tfrac{1}{3}\right) + n\pi, \quad n = 0, \pm 1, \pm 2, \ldots \end{equation*}
    By part 2 of Remark 3.4.1, since \(A = -1/3 \lt 0\text{,}\) the valid solutions with \(t \geq 0\) start at \(n = 1\text{.}\)
    🔗
    🔗
    So starting at \(n = 1\) ensures every value of \(t\) is nonnegative, and the mass changes direction at:
    \begin{equation*} t = \arctan\!\left(-\tfrac{1}{3}\right) + n\pi, \quad n = 1, 2, 3, \ldots \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Observation 3.4.3. Direction Changes in the Mass-Spring System.

    In the mass-spring system, direction changes always correspond to critical points of \(x(t)\text{,}\) i.e., times when \(x'(t) = 0\text{.}\)
    🔗
    While in general a function can have critical points that are saddle points (not direction changes), this does not happen in the mass-spring system. When the velocity \(x'(t)\) slows down to zero, the physics of the spring forces the mass to turn in the opposite direction: the spring cannot stretch, slow to zero velocity, and then continue stretching. So every critical point is a genuine direction change.
    🔗
    🔗

    Key Takeaways.

    • Direction changes correspond to critical points: the mass changes direction exactly when \(x'(t) = 0\text{.}\)
      🔗
      🔗
    • Solving \(x'(t) = 0\text{:}\) after computing \(x'(t)\) and dividing out \(e^{\alpha t}\text{,}\) we arrive at \(\tan(t) = A\) for some constant \(A\text{,}\) giving \(t = \arctan(A) + n\pi\text{.}\) To get \(t \geq 0\text{:}\) if \(A \geq 0\text{,}\) start at \(n = 0\text{;}\) if \(A \lt 0\text{,}\) start at \(n = 1\text{.}\)
