    Section 3.1.4 Practice: Real Roots

    Recall that for \(ay'' + by' + cy = 0\text{,}\) if the characteristic equation has:
    • Two distinct real roots \(r_1 \neq r_2\text{:}\) general solution \(y = c_1 e^{r_1 x} + c_2 e^{r_2 x}\)
      🔗
      🔗
    • One repeated real root \(r_1\text{:}\) general solution \(y = c_1 e^{r_1 x} + c_2 x e^{r_1 x}\)
      🔗
      🔗
    We justified the distinct roots case on a previous page. Let’s justify the repeated root case now.
    🔗

    Theorem 3.1.1. Why Does the Repeated Root Case Give \(xe^{r_1 x}\text{?}\)

    If \(r_1\) is a repeated root of \(ar^2 + br + c = 0\text{,}\) then \(y_1 = e^{r_1 x}\) and \(y_2 = xe^{r_1 x}\) are two linearly independent solutions to \(ay'' + by' + cy = 0\text{.}\)
    🔗
    🔗

    Justification (can skim).

    Since \(r_1\) is a repeated root, the characteristic equation factors as \(a(r - r_1)^2 = 0\text{,}\) which means \(b = -2ar_1\) and \(c = ar_1^2\text{.}\) We already know \(y_1 = e^{r_1 x}\) is a solution. We need to verify \(y_2 = xe^{r_1 x}\) is also a solution.
    🔗
    Computing the derivatives of \(y_2 = xe^{r_1 x}\text{:}\)
    \begin{align*} y_2' \amp= e^{r_1 x} + r_1 xe^{r_1 x} = (1 + r_1 x)e^{r_1 x}\\ y_2'' \amp= r_1 e^{r_1 x} + r_1(1 + r_1 x)e^{r_1 x} = (2r_1 + r_1^2 x)e^{r_1 x} \end{align*}
    Substituting into \(ay_2'' + by_2' + cy_2\text{:}\)
    \begin{align*} \amp= a(2r_1 + r_1^2 x)e^{r_1 x} + b(1 + r_1 x)e^{r_1 x} + cxe^{r_1 x}\\ \amp= e^{r_1 x}\left[(2ar_1 + b) + (ar_1^2 + br_1 + c)x\right] \end{align*}
    Since \(r_1\) is a root: \(ar_1^2 + br_1 + c = 0\text{.}\) And since it is a repeated root: \(2ar_1 + b = 0\text{.}\) So both terms vanish:
    \begin{equation*} ay_2'' + by_2' + cy_2 = e^{r_1 x}[0 + 0] = 0. \checkmark \end{equation*}
    Finally, \(y_1 = e^{r_1 x}\) and \(y_2 = xe^{r_1 x}\) are not constant multiples of each other, so they are linearly independent.
    🔗
    🔗
    These first two cases are straightforward enough, but the activity below has some fun twists where it may not be immediately obvious how to proceed.
    🔗

    Activity 3.1.1. Practice: Real Roots.

    (a) Solve \(y'' + 2y' + y = 0\).

    Find the general solution to \(y'' + 2y' + y = 0\text{.}\)
    🔗
    Hint.
    The characteristic equation is \(r^2 + 2r + 1 = 0\text{.}\) Try factoring it!
    🔗
    🔗
    Solution.
    The characteristic equation is \(r^2 + 2r + 1 = 0\text{,}\) which factors as:
    \begin{equation*} (r + 1)^2 = 0. \end{equation*}
    This gives a repeated root \(r_1 = -1\text{.}\) The general solution is:
    \begin{equation*} y = c_1 e^{-x} + c_2 x e^{-x}. \end{equation*}
    🔗
    🔗
    🔗

    (b) Solve \(y'' - y' = 0\).

    Find the general solution to \(y'' - y' = 0\text{.}\)
    🔗
    Hint.
    The characteristic equation is \(r^2 - r = 0\text{.}\) Factor out an \(r\text{.}\)
    🔗
    🔗
    Solution.
    The characteristic equation is \(r^2 - r = 0\text{,}\) which factors as:
    \begin{equation*} r(r - 1) = 0. \end{equation*}
    So \(r_1 = 0\) and \(r_2 = 1\text{.}\) These are two distinct real roots, giving:
    \begin{equation*} y_1 = e^{0 \cdot x} = 1 \qquad \text{and} \qquad y_2 = e^{x}. \end{equation*}
    The general solution is:
    \begin{equation*} y = c_1 + c_2 e^{x}. \end{equation*}
    Notice that \(r = 0\) as a root just gives a constant solution: perfectly valid!
    🔗
    🔗
    🔗

    (c) Solve \(y'' = 0\).

    Find the general solution to \(y'' = 0\text{.}\)
    🔗
    Hint.
    The characteristic equation is \(r^2 = 0\text{.}\) What are the roots?
    🔗
    🔗
    Solution.
    The characteristic equation is \(r^2 = 0\text{,}\) giving a repeated root \(r_1 = 0\text{.}\) By the repeated root case:
    \begin{equation*} y_1 = e^{0 \cdot x} = 1 \qquad \text{and} \qquad y_2 = xe^{0 \cdot x} = x. \end{equation*}
    The general solution is:
    \begin{equation*} y = c_1 + c_2 x. \end{equation*}
    This makes sense: if the second derivative is zero, the function must be linear!
    🔗
    🔗
    🔗
    🔗

    Key Takeaways.

    • The method always applies: any ODE of the form \(ay'' + by' + cy = 0\) has a characteristic equation \(ar^2 + br + c = 0\text{.}\) Even when the ODE looks unusual, like \(y'' - y' = 0\) or \(y'' = 0\text{,}\) you can always identify \(a\text{,}\) \(b\text{,}\) and \(c\) and proceed the same way.
      🔗
      🔗
    • Watch for surprises: a root of \(r = 0\) just gives a constant or linear solution, which is perfectly valid.
