    Section 4.2.1 Partial Fraction Decomposition Review

    In the next few pages we will need to decompose rational functions into simpler fractions before taking inverse Laplace transforms. There are three cases that come up in this chapter. For each one, the key skill is recognizing the correct form of the decomposition and then solving for the unknown constants.
    🔗
    Case 1: Distinct Linear Factors. If the denominator factors into two distinct linear factors \((s - r_1)(s - r_2)\text{,}\) each factor gets its own fraction with a constant numerator:
    \begin{equation*} \frac{P(s)}{(s-r_1)(s-r_2)} = \frac{A}{s-r_1} + \frac{B}{s-r_2}. \end{equation*}
    🔗
    Case 2: One Linear Factor and One Irreducible Quadratic Factor. A quadratic \(s^2 + bs + c\) is irreducible if it has no real roots, which happens when \(b^2 - 4c \lt 0\text{.}\) In this chapter the quadratics that appear are always of the form \(s^2 + k\) with \(k \gt 0\text{,}\) which are always irreducible. An irreducible quadratic factor gets a linear numerator \(Bs + C\text{:}\)
    \begin{equation*} \frac{P(s)}{s(s^2+k)} = \frac{A}{s} + \frac{Bs+C}{s^2+k}. \end{equation*}
    🔗
    Case 3: Repeated Linear Factor. If a linear factor \((s - r)\) appears squared, we need one fraction for each power:
    \begin{equation*} \frac{P(s)}{(s-r)^2(s-r_2)} = \frac{A}{s-r} + \frac{B}{(s-r)^2} + \frac{C}{s-r_2}. \end{equation*}
    For example, with \(s^2 = s \cdot s\) (i.e. \(r = 0\) repeated twice):
    \begin{equation*} \frac{P(s)}{s^2(s+4)} = \frac{A}{s} + \frac{B}{s^2} + \frac{C}{s+4}. \end{equation*}
    🔗

    Checkpoint 4.2.1.

    Which of the following is the correct partial fraction form for \(\dfrac{1}{(s-2)(s+4)}\text{?}\)
    🔗
    • \(\dfrac{A}{s-2} + \dfrac{B}{s+4}\)
    • Correct! Two distinct linear factors each get a constant numerator.
    • \(\dfrac{A}{s-2} + \dfrac{B}{(s+4)^2}\)
    • The squared denominator form is for repeated factors. Here \(s+4\) appears only once.
    • \(\dfrac{As+B}{s-2} + \dfrac{Cs+D}{s+4}\)
    • Linear numerators like \(As+B\) are for irreducible quadratic factors. For linear factors the numerator is just a constant.
    • \(\dfrac{A}{s-2} + \dfrac{B}{s+4} + \dfrac{C}{(s-2)(s+4)}\)
    • There is no need for a fraction with the full original denominator. Two distinct linear factors give exactly two terms.
    🔗

    Checkpoint 4.2.2.

    Which of the following is the correct partial fraction form for \(\dfrac{1}{s(s^2+4)}\text{?}\)
    🔗
    • \(\dfrac{A}{s} + \dfrac{Bs+C}{s^2+4}\)
    • Correct! The linear factor \(s\) gets a constant numerator, and the irreducible quadratic \(s^2+4\) gets a linear numerator \(Bs+C\text{.}\)
    • \(\dfrac{A}{s} + \dfrac{B}{s^2+4}\)
    • The irreducible quadratic factor needs a linear numerator \(Bs+C\text{,}\) not just a constant.
    • \(\dfrac{A}{s} + \dfrac{B}{s^2} + \dfrac{C}{4}\)
    • \(s^2 + 4\) is irreducible and cannot be split further. It stays as one factor with a linear numerator.
    • \(\dfrac{As+B}{s} + \dfrac{Cs+D}{s^2+4}\)
    • The factor \(s\) is linear, so its numerator is just a constant \(A\text{,}\) not \(As+B\text{.}\)
    🔗

    Checkpoint 4.2.3.

    Which of the following is the correct partial fraction form for \(\dfrac{1}{s^2(s+4)}\text{?}\)
    🔗
    • \(\dfrac{A}{s} + \dfrac{B}{s^2} + \dfrac{C}{s+4}\)
    • Correct! The repeated factor \(s^2\) contributes two fractions, one for each power, and the distinct factor \(s+4\) gets its own.
    • \(\dfrac{A}{s^2} + \dfrac{B}{s+4}\)
    • When \(s\) appears as a repeated factor you need a fraction for \(s\) and a separate one for \(s^2\text{.}\)
    • \(\dfrac{A}{s} + \dfrac{Bs+C}{s^2} + \dfrac{D}{s+4}\)
    • Linear numerators like \(Bs+C\) are for irreducible quadratics. Since \(s^2\) is a repeated linear factor each piece just gets a constant numerator.
    • \(\dfrac{A}{s} + \dfrac{B}{s} + \dfrac{C}{s+4}\)
    • You cannot use the same denominator \(s\) twice. The repeated factor \(s^2\) contributes one fraction with \(s\) and one with \(s^2\) in the denominator.
    🔗

    Example 4.2.4. Solving for Coefficients by Clearing Denominators.

    Find the partial fraction decomposition of \(\dfrac{1}{(s-2)(s+4)}\text{.}\)
    🔗
    From Case 1, the correct form is
    \begin{equation*} \frac{1}{(s-2)(s+4)} = \frac{A}{s-2} + \frac{B}{s+4}. \end{equation*}
    Multiply both sides by \((s-2)(s+4)\) to clear the denominators:
    \begin{equation*} 1 = A(s+4) + B(s-2). \end{equation*}
    Expand:
    \begin{align*} 1 \amp= As + 4A + Bs - 2B\\ \underbrace{0}_{\text{coeff of }s} \cdot s + \underbrace{1}_{\text{const}} \amp= \underbrace{(A+B)}_{\text{coeff of }s} \cdot s + \underbrace{(4A - 2B)}_{\text{const}}. \end{align*}
    Equating the coefficient of \(s\) on both sides, and then the constant:
    \begin{align*} A + B \amp= 0\\ 4A - 2B \amp= 1. \end{align*}
    Matching coefficients (the left side has \(0 \cdot s + 1\)):
    \begin{align*} A + B \amp= 0\\ 4A - 2B \amp= 1. \end{align*}
    From the first equation \(B = -A\text{.}\) Substituting into the second: \(4A + 2A = 6A = 1\text{,}\) so \(A = \dfrac{1}{6}\) and \(B = -\dfrac{1}{6}\text{.}\) Therefore:
    \begin{equation*} \frac{1}{(s-2)(s+4)} = \frac{\frac{1}{6}}{s-2} - \frac{\frac{1}{6}}{s+4}. \end{equation*}
    🔗
    🔗

    Key Takeaways.

    • Distinct linear factors \((s-r_1)(s-r_2)\text{:}\) each gets a constant numerator.
      🔗
      🔗
    • Irreducible quadratic \(s^2+k\) with \(k \gt 0\text{:}\) gets a linear numerator \(Bs+C\text{.}\) Note that \(s^2+k\) is always irreducible when \(k \gt 0\text{.}\)
      🔗
      🔗
    • Repeated linear factor \((s-r)^2\text{:}\) contributes two fractions, one with \((s-r)\) and one with \((s-r)^2\) in the denominator.
      🔗
      🔗
    • To solve for coefficients: multiply both sides by the full denominator to clear it, expand, and match coefficients of each power of \(s\text{.}\)
