    Section 3.1.1 Introduction to Second-Order Linear ODEs

    So far we’ve been working with first-order ODEs. But second-order ODEs show up naturally in many applications. We’ll actually see an interesting example with the mass-spring system later in this chapter, where the second derivative appears because of acceleration. Before we get to the fun stuff, we need to spend this section understanding the mathematics of the ODE and learning how to fully solve a simple case!
    🔗

    Definition 3.1.1. Second-Order Linear ODE.

    A second-order linear differential equation can be written in the form:
    \begin{equation*} P_0(x)y'' + P_1(x)y' + P_2(x)y = Q(x), \end{equation*}
    where \(P_0(x)\text{,}\) \(P_1(x)\text{,}\) \(P_2(x)\text{,}\) and \(Q(x)\) are functions of \(x\text{.}\)
    🔗
    🔗
    For example, the equation
    \begin{equation*} \underbrace{x^2}_{P_0(x)}y'' + \underbrace{1}_{P_1(x)}y' + \underbrace{e^x}_{P_2(x)}y = \underbrace{\sin(x)+3}_{Q(x)} \end{equation*}
    is a second-order linear ODE, with the coefficient functions and right-hand side labeled. Also, notice that if you remove the \(y''\) term, you are left with a first-order linear ODE! You can extend this definition to a linear ODE of any order, but for our own sanity we will stop at second-order.
    🔗

    Checkpoint 3.1.2.

    Select all equations that are second-order linear ODEs.
    🔗
    • \(y'' + 3xy' - e^x y = \cos(x)\)
    • Correct! This fits the form \(P_0 y'' + P_1 y' + P_2 y = Q(x)\) with \(P_0 = 1\text{,}\) \(P_1 = 3x\text{,}\) \(P_2 = -e^x\text{,}\) and \(Q(x) = \cos(x)\text{.}\) \(\checkmark\)
    • \(x^2 y'' = \sin(x) - y' + xy\)
    • Correct! This is not in standard form, but rearranging gives \(x^2 y'' + y' - xy = \sin(x)\text{,}\) which fits the form with \(P_0 = x^2\text{,}\) \(P_1 = 1\text{,}\) \(P_2 = -x\text{.}\) \(\checkmark\)
    • \(yy'' + y' = 0\)
    • Not quite. The term \(yy''\) is a product of \(y\) with its second derivative, which makes this equation nonlinear.
    • \(y'' + (y')^2 = x\)
    • Not quite. The term \((y')^2\) means \(y'\) appears to a power higher than 1, so this equation is nonlinear.
    • \(y' + 3y = x^2\)
    • This is linear, but only first-order. There is no \(y''\) term.
    🔗

    Definition 3.1.3. Homogeneous Second-Order Linear ODE.

    A second-order linear ODE is called homogeneous when \(Q(x) = 0\text{.}\) That is, it has the form:
    \begin{equation*} P_0(x)y'' + P_1(x)y' + P_2(x)y = 0. \end{equation*}
    🔗
    🔗
    Here’s a quick way to see the difference:
    \begin{align*} x^2 y'' + y' + e^x y \amp= \sin(x) + 3 \quad \leadsto \text{ not homogeneous}\\ x^2 y'' + y' + e^x y \amp= 0 \hphantom{\sin(x) + 3} \quad \leadsto \text{ homogeneous} \end{align*}
    Same left-hand side, but setting the right-hand side to zero makes it homogeneous.
    🔗
    We now arrive at a very consequential observation regarding linear ODEs. We state it for second-order, but it is true for any linear ODE, and it is part of what makes linear ODEs so nice to work with.
    🔗

    Observation 3.1.4. The Principle of Superposition.

    If \(y_1\) and \(y_2\) are both solutions to a second-order linear homogeneous ODE, then
    \begin{equation*} y = c_1 y_1 + c_2 y_2 \end{equation*}
    is also a solution, for any constants \(c_1\) and \(c_2\text{.}\)
    🔗
    🔗
    You can skim through the proof below and come back to it if you’re curious.
    🔗

    Proof of Superposition (can skim).

    Suppose \(y_1\) and \(y_2\) both satisfy \(P_0 y'' + P_1 y' + P_2 y = 0\text{.}\) Let \(y = c_1 y_1 + c_2 y_2\text{.}\) We check that \(y\) satisfies the ODE:
    \begin{align*} P_0 y'' + P_1 y' + P_2 y \amp= P_0(c_1 y_1 + c_2 y_2)'' + P_1(c_1 y_1 + c_2 y_2)' + P_2(c_1 y_1 + c_2 y_2)\\ \amp= P_0(c_1 y_1'' + c_2 y_2'') + P_1(c_1 y_1' + c_2 y_2') + P_2(c_1 y_1 + c_2 y_2)\\ \amp= c_1\underbrace{(P_0 y_1'' + P_1 y_1' + P_2 y_1)}_{=\,0} + c_2\underbrace{(P_0 y_2'' + P_1 y_2' + P_2 y_2)}_{=\,0}\\ \amp= 0. \end{align*}
    So \(y = c_1 y_1 + c_2 y_2\) satisfies the ODE. \(\checkmark\)
    🔗
    🔗
    It is important to understand that the principle of superposition requires the ODE to be both linear and homogeneous. If either fails, we cannot expect this principle to hold. In the following example, we show that it can fail in the nonlinear case.
    🔗

    Example 3.1.5. Superposition Can Fail for Nonlinear ODEs.

    The superposition principle requires the ODE to be both linear and homogeneous. Let’s see what happens when it’s not. Show that \(y_1 = 1\) and \(y_2 = \sqrt{x}\) are both solutions to
    \begin{equation*} yy'' + (y')^2 = 0, \end{equation*}
    but their sum \(y = y_1 + y_2 = 1 + \sqrt{x}\) is not a solution.
    🔗
    Solution. Can skim for now
    Checking \(y_1 = 1\text{:}\) We have \(y_1' = 0\) and \(y_1'' = 0\text{,}\) so:
    \begin{equation*} y_1 y_1'' + (y_1')^2 = (1)(0) + (0)^2 = 0. \checkmark \end{equation*}
    🔗
    Checking \(y_2 = \sqrt{x}\text{:}\) We have \(y_2' = \dfrac{1}{2\sqrt{x}}\) and \(y_2'' = -\dfrac{1}{4x^{3/2}}\text{,}\) so:
    \begin{equation*} y_2 y_2'' + (y_2')^2 = \sqrt{x} \cdot \left(-\frac{1}{4x^{3/2}}\right) + \left(\frac{1}{2\sqrt{x}}\right)^2 = -\frac{1}{4x} + \frac{1}{4x} = 0. \checkmark \end{equation*}
    🔗
    Checking \(y = 1 + \sqrt{x}\text{:}\) We have \(y' = \dfrac{1}{2\sqrt{x}}\) and \(y'' = -\dfrac{1}{4x^{3/2}}\text{,}\) so:
    \begin{align*} yy'' + (y')^2 \amp= (1 + \sqrt{x})\left(-\frac{1}{4x^{3/2}}\right) + \frac{1}{4x}\\ \amp= -\frac{1}{4x^{3/2}} - \frac{1}{4x} + \frac{1}{4x}\\ \amp= -\frac{1}{4x^{3/2}} \neq 0. \end{align*}
    So the sum is not a solution. This makes sense: superposition only applies to linear homogeneous ODEs, and \(yy'' + (y')^2 = 0\) is nonlinear.
    🔗
    🔗
    🔗
    We end with one more example, this time confirming that the principle of superposition works in a specific case. By the way, this is not just a random homogeneous linear ODE. We will be studying ODEs of this type extensively for the rest of this section.
    🔗

    Example 3.1.6. Superposition in Action.

    It is easy to check that \(y_1 = e^{2x}\) and \(y_2 = e^{3x}\) are both solutions to the second-order linear homogeneous ODE:
    \begin{equation*} y'' - 5y' + 6y = 0. \end{equation*}
    By the superposition principle, any combination \(y = c_1e^{2x} + c_2e^{3x}\) should also be a solution. Let’s confirm this for \(y = 2e^{2x} + 5e^{3x}\text{.}\)
    🔗
    Solution.
    We compute the derivatives of \(y = 2e^{2x} + 5e^{3x}\text{:}\)
    \begin{align*} y' \amp= 4e^{2x} + 15e^{3x}\\ y'' \amp= 8e^{2x} + 45e^{3x} \end{align*}
    Now substitute into \(y'' - 5y' + 6y\text{:}\)
    \begin{align*} \amp\underbrace{(8e^{2x} + 45e^{3x})}_{y''} - 5\underbrace{(4e^{2x} + 15e^{3x})}_{y'} + 6\underbrace{(2e^{2x} + 5e^{3x})}_{y}\\ \amp= e^{2x}(8 - 20 + 12) + e^{3x}(45 - 75 + 30)\\ \amp= e^{2x}(0) + e^{3x}(0) = 0. \checkmark \end{align*}
    Superposition works (as it should!).
    🔗
    🔗
    🔗
    Notice in the example above how the \(e^{2x}\) terms collected together and the \(e^{3x}\) terms collected together, each summing to zero independently. The fact that the ODE was linear was key for splitting the expressions over the sum, and it being homogeneous is why both parts summed to 0. This is at the heart of why superposition principle works.
    🔗

    Key Takeaways.

    • Second-order linear ODE: Has the form \(P_0(x)y'' + P_1(x)y' + P_2(x)y = Q(x)\text{.}\) It is homogeneous when \(Q(x) = 0\text{.}\)
      🔗
      🔗
    • Superposition: If \(y_1\) and \(y_2\) are solutions to a linear homogeneous ODE, then so is \(c_1 y_1 + c_2 y_2\) for any constants \(c_1\) and \(c_2\text{.}\)
      🔗
      🔗
    • Linearity matters for superposition: Superposition can fail for nonlinear ODEs, as we saw in the counterexample. The homogeneous condition is required as well.
