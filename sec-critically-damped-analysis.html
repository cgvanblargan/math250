    Section 3.4.4 Analyzing a Critically Damped System

    We continue analyzing overdamped and critically damped systems. Recall the shared behavior of these two cases.
    🔗

    Summary: Overdamped and Critically Damped Cases of \(mx'' + cx' + kx = 0\).

    Case Discriminant and roots Crossings of \(x=0\) \(\displaystyle\lim_{t\to\infty} x(t)\)
    Overdamped (larger \(c\)) \(c^2 > 4km\) (two distinct real roots) At most once \(0\)
    Critically damped (borderline) \(c^2 = 4km\) (one repeated real root) At most once \(0\)
    🔗
    Consider the spring-mass-dashpot system with \(m = 1\text{,}\) \(c = 4\text{,}\) \(k = 4\text{,}\) set in motion at \(t = 0\) with \(x(0) = 1\) and \(x'(0) = 2\text{.}\) Substituting these parameters gives the IVP:
    \begin{equation*} x'' + 4x' + 4x = 0, \quad x(0) = 1, \quad x'(0) = 2. \end{equation*}
    The solution to this IVP is:
    \begin{equation*} x(t) = e^{-2t}(1 + 4t). \end{equation*}
    🔗
    Solution. Work: Solution to the IVP (can skim)
    With \(m=1\text{,}\) \(c=4\text{,}\) \(k=4\) the characteristic equation is \(r^2 + 4r + 4 = 0\text{,}\) which factors as \((r+2)^2 = 0\text{.}\) This gives one repeated root \(r = -2\text{,}\) confirming the system is critically damped. The general solution is:
    \begin{equation*} x(t) = e^{-2t}(c_1 + c_2 t). \end{equation*}
    Applying \(x(0) = 1\text{:}\) \(c_1 = 1\text{.}\) Differentiating:
    \begin{equation*} x'(t) = -2e^{-2t}(c_1 + c_2 t) + e^{-2t}(c_2). \end{equation*}
    Applying \(x'(0) = 2\text{:}\)
    \begin{equation*} x'(0) = -2c_1 + c_2 = 2 \implies c_2 = 2 + 2(1) = 4. \end{equation*}
    So \(x(t) = e^{-2t}(1 + 4t)\text{.}\)
    🔗
    🔗

    Example 3.4.1. Sketching the Graph from Initial Conditions.

    (a) Does the Mass Pass Through Equilibrium?

    Does the mass ever pass through the equilibrium position \(x = 0\) for \(t \geq 0\text{?}\)
    🔗
    Hint.
    Set \(x(t) = 0\) and solve for \(t\text{.}\) Since \(e^{-2t} \neq 0\text{,}\) focus on the other factor. Remember that only \(t \geq 0\) is physically meaningful.
    🔗
    🔗
    Solution.
    We solve \(e^{-2t}(1 + 4t) = 0\text{.}\) Since \(e^{-2t} \neq 0\text{,}\) we need \(1 + 4t = 0\text{,}\) giving \(t = -\tfrac{1}{4} \lt 0\text{.}\) Since this is not a valid time, the mass never passes through equilibrium for \(t \geq 0\text{.}\)
    🔗
    🔗
    🔗

    (b) What Do the Initial Conditions Tell Us?

    What do the initial conditions \(x(0) = 1\) and \(x'(0) = 2\) tell us about the behavior of the mass?
    🔗
    Hint.
    We were given \(x(0)\) and \(x'(0)\) in the problem setup. Are they positive or negative? Recall that \(x > 0\) means stretched and \(x \lt 0\) means compressed, while the sign of \(x'\) tells us the direction of motion.
    🔗
    🔗
    Solution.
    Since \(x(0) = 1 > 0\text{,}\) the mass starts stretched. Since \(x'(0) = 2 > 0\text{,}\) the mass is initially moving in the positive direction, meaning it is becoming even more stretched at first. Together with the result of the previous task, the mass starts stretched, moves further from equilibrium, and then approaches zero from above without ever crossing it.
    🔗
    🔗
    🔗

    (c) Putting It Together.

    Combining the two observations above: the mass starts stretched, initially moves further from equilibrium, never crosses \(x = 0\text{,}\) and eventually approaches zero from above. This gives the following graph.

    Activity 3.4.1. Analyzing the Behavior.

    We continue with the same position function,
    \begin{equation*} x(t) = e^{-2t}(1 + 4t). \end{equation*}
    Now that we have a complete picture of the motion, we use it to answer questions about the system. Make sure to reference the previous example to help answer the following questions.
    🔗

    (a) Is the Spring Ever Compressed?

    Explain how you can tell the spring is never compressed.
    🔗
    • \(x(0) > 0\) and the mass never crosses the equilibrium position, so \(x(t) > 0\) for all \(t \geq 0\text{.}\)
    • Correct! Since \(x(0) = 1 > 0\) (starts stretched) and the mass never reaches \(x = 0\text{,}\) it stays on the stretched side for all time. \(\checkmark\)
    • \(x'(0) > 0\text{,}\) so the mass is moving away from the compressed region.
    • The sign of \(x'(0)\) tells us the initial direction of motion, but alone it does not guarantee the spring is never compressed. The key facts are that \(x(0) > 0\) and the mass never crosses equilibrium.
    • The system is critically damped, so it cannot become compressed.
    • The damping case alone does not determine whether the spring is compressed. A critically damped system can start compressed and remain so. What matters here is the combination of initial conditions and the equilibrium crossing result.
    🔗

    (b) Find the Time of Maximum Stretch.

    Find the exact time at which the mass is farthest from the equilibrium position.
    🔗
    Hint.
    The maximum stretch occurs either at:
    • \(t = 0\text{,}\) or
      🔗
      🔗
    • a critical point where \(x'(t) = 0\text{.}\)
      🔗
      🔗
    Looking back at the graph from the previous example, can you deduce which one it is?
    🔗
    🔗
    Solution.
    Since \(x'(0) = 2 > 0\text{,}\) the mass is still moving away from equilibrium at \(t = 0\text{,}\) so the maximum stretch does not occur at \(t = 0\text{.}\) It must occur at a critical point where \(x'(t) = 0\text{,}\) so we compute \(x'(t)\) and solve.
    🔗
    Solution 1. Step 1: Compute \(x'(t)\)
    Using the product rule on \(x(t) = e^{-2t}(1 + 4t)\text{:}\)
    \begin{align*} x'(t) \amp= -2e^{-2t}(1 + 4t) + e^{-2t}(4)\\ \amp= e^{-2t}(-2 - 8t + 4)\\ \amp= e^{-2t}(2 - 8t). \end{align*}
    🔗
    🔗
    So \(x'(t) = e^{-2t}(2 - 8t)\text{.}\) Now we set this equal to zero and solve.
    🔗
    Solution 2. Step 2: Solve \(x'(t) = 0\)
    We need to solve:
    \begin{equation*} e^{-2t}(2 - 8t) = 0. \end{equation*}
    Since \(e^{-2t} \neq 0\text{,}\) we need:
    \begin{equation*} 2 - 8t = 0 \implies t = \frac{1}{4}. \end{equation*}
    So the maximum stretch occurs at \(t = \tfrac{1}{4}\text{,}\) where \(x\!\left(\tfrac{1}{4}\right) = e^{-1/2}(1 + 1) = 2e^{-1/2} \approx 1.21\text{.}\)
    🔗
    🔗
    The graph below shows the maximum stretch marked at \(t = \tfrac{1}{4}\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Key Takeaways.

    • Finding the farthest point from equilibrium: this always happens either at \(t = 0\) or at a critical point where \(x'(t) = 0\text{.}\)
      🔗
      🔗
    • How to tell which one: you can determine this from a sketch of the graph. In particular, check the sign of \(x'(0)\text{:}\) if the mass is moving toward equilibrium at \(t = 0\text{,}\) then \(t = 0\) is already the farthest point. But if the mass is moving away from equilibrium, as in this example (\(x'(0) = 2 > 0\) on the stretched side), then it gets even farther before turning around, so the farthest point occurs at a later critical point, which we find by solving \(x'(t) = 0\text{.}\)
      🔗
      🔗
    • Note for underdamped systems: the same logic applies, but since underdamped solutions oscillate, there are infinitely many critical points, one at each direction change. The farthest point from equilibrium is still either \(t = 0\) or the first critical point, but the mass continues changing direction forever after that.
