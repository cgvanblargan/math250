    Section 3.2.3 Passing Through Equilibrium

    As we said on the previous page, from here on out we are exploring the behavior of the solutions to the mass-spring system.
    🔗
    We know the mass oscillates forever in free undamped motion. Let’s think about a specific question: how many times does it pass through equilibrium (\(x=0\) ) as time goes to infinity? Play around with the graph below and see what you notice.
    🔗

    Checkpoint 3.2.2.

    Based on the graph above, how many times does a mass undergoing free undamped simple harmonic motion pass through equilibrium (\(x = 0\)) as \(t \to \infty\text{?}\)
    🔗
    • A finite number of times, depending on \(c_1\) and \(c_2\text{.}\)
    • Try changing \(c_1\) and \(c_2\) in the interactive above. The mass keeps crossing equilibrium regardless. The amplitude changes, but the oscillation never stops.
    • A finite number of times, depending on \(\omega_0\text{.}\)
    • Changing \(\omega_0\) makes the mass oscillate faster or slower, but it never stops oscillating. The crossings keep coming, forever.
    • Infinitely many times, regardless of \(c_1\text{,}\) \(c_2\text{,}\) or \(\omega_0\text{.}\)
    • Exactly. Since there’s no damping, the amplitude stays fixed and the mass oscillates forever, crossing \(x = 0\) twice per period, indefinitely. \(\checkmark\)
    • Zero times. The mass never reaches exactly \(x = 0\) unless it starts there.
    • The mass absolutely does pass through \(x = 0\text{!}\) Watch the counter in the interactive. Unless the solution is identically zero (which requires \(c_1 = c_2 = 0\)), the oscillation crosses equilibrium repeatedly.
    🔗
    Notice that no matter what you set the sliders to (as long as the solution isn’t identically zero), the mass oscillates with a fixed amplitude, so it keeps crossing the equilibrium (\(x=0\)) forever. This is a key feature of undamped motion. There is nothing slowing it down, so the force from the spring has it just repeat the same oscillations for all of time!
    🔗
    While it seems clear from the graph, we should always be able to back this up algebraically. We do this in the following example.
    🔗

    Example 3.2.3. Showing Infinitely Many Equilibrium Crossings.

    Let \(x(t) = c_1\cos(\omega_0 t) + c_2\sin(\omega_0 t)\) be the general solution to an undamped mass-spring system, where \(\omega_0 \gt 0\) and \(c_1, c_2\) are not both zero. Show that \(x(t) = 0\) has infinitely many solutions.
    🔗
    Hint.
    Set \(x(t) = 0\) and solve for \(t\text{.}\)
    🔗
    🔗
    Solution.
    We want to solve \(x(t) = 0\text{,}\) i.e.:
    \begin{equation*} c_1\cos(\omega_0 t) + c_2\sin(\omega_0 t) = 0. \end{equation*}
    🔗
    Case 1: \(c_2 = 0\text{.}\) Then \(x(t) = c_1\cos(\omega_0 t) = 0\text{.}\) Since \(c_1 \neq 0\) (not both zero), we need \(\cos(\omega_0 t) = 0\text{,}\) which gives:
    \begin{equation*} \omega_0 t = \frac{\pi}{2} + n\pi, \qquad n = 0, 1, 2, 3, \ldots \end{equation*}
    so \(t = \dfrac{1}{\omega_0}\!\left(\dfrac{\pi}{2} + n\pi\right)\text{.}\) This is a different value of \(t\) for each \(n\text{,}\) so infinitely many solutions.
    🔗
    Case 2: \(c_2 \neq 0\text{.}\) Rearranging:
    \begin{align*} c_1\cos(\omega_0 t) \amp= -c_2\sin(\omega_0 t). \end{align*}
    Dividing both sides by \(c_2\cos(\omega_0 t)\text{:}\)
    \begin{equation*} \tan(\omega_0 t) = -\frac{c_1}{c_2}. \end{equation*}
    Solving for \(t\text{:}\)
    \begin{equation*} \omega_0 t = \arctan\!\left(-\frac{c_1}{c_2}\right) + n\pi \end{equation*}
    \begin{equation*} t = \frac{1}{\omega_0}\left[\arctan\!\left(-\frac{c_1}{c_2}\right) + n\pi\right]. \end{equation*}
    Since we need \(t \geq 0\text{,}\) we take \(n\) to be whichever non-negative integers keep \(t\) positive (starting at \(n = 0\) or \(n = 1\) depending on the sign of the arctan term). Either way, there are infinitely many valid values of \(t\text{.}\)
    🔗
    Solution. Why \(+ \, n\pi\text{?}\) (if unsure: click for a trig review)
    Two things are going on here. First, \(\arctan\) only gives us one solution: it’s the inverse of \(\tan\) restricted to \((-\pi/2, \pi/2)\text{.}\) So \(\arctan(-c_1/c_2)\) is just the first value of \(\omega_0 t\) that works.
    🔗
    Second, tangent has period \(\pi\text{,}\) meaning \(\tan(\theta) = \tan(\theta + \pi)\) for any \(\theta\text{.}\) So if \(\omega_0 t = \theta_0\) is a solution to \(\tan(\omega_0 t) = -c_1/c_2\text{,}\) then so is \(\omega_0 t = \theta_0 + \pi\text{,}\) and \(\theta_0 + 2\pi\text{,}\) and so on. That’s where the \(+ \, n\pi\) comes from, capturing all solutions at once.
    🔗
    (Note: \(\tan\) has period \(\pi\text{,}\) not \(2\pi\) like sine and cosine. So we add multiples of \(\pi\text{,}\) not \(2\pi\text{.}\))
    🔗
    🔗
    Since \(n\) ranges over all integers, this gives infinitely many values of \(t\text{,}\) one for each \(n\text{.}\) No matter what \(c_1\text{,}\) \(c_2\text{,}\) and \(\omega_0\) are, the mass passes through equilibrium infinitely many times.
    🔗
    🔗
    🔗

    Key Takeaways.

    • Graphical observation: free undamped simple harmonic motion oscillates with fixed amplitude forever. So the mass passes through equilibrium (\(x = 0\)) infinitely many times.
      🔗
      🔗
    • Algebraic justification: setting \(x(t) = 0\) and solving gives
      \begin{equation*} t = \frac{1}{\omega_0}\left[\arctan\!\left(-\frac{c_1}{c_2}\right) + n\pi\right], \quad n = 0, 1, 2, \ldots \end{equation*}
      (or \(t = \frac{1}{\omega_0}\!\left(\frac{\pi}{2} + n\pi\right)\) when \(c_2 = 0\)). Either way, there are infinitely many times at which the mass passes through equilibrium.
      🔗
      🔗
    • This is a feature of free undamped motion: no energy is lost, so the oscillation never dies out. When we add damping later, this will change!
