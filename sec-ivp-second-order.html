    Section 3.1.6 Initial Value Problems

    So far we have only been finding the general solution to \(ay'' + by' + cy = 0\text{.}\) Just like with first-order ODEs, we can also solve initial value problems. However, there is one noticeable difference. With first-order ODEs, we only had one constant \(C\) to solve for. For example, \(P(t) = Ce^{2t}\) solves \(\frac{dP}{dt} = 2P\text{,}\) and knowing \(P(0)\) let us solve for \(C\text{.}\)
    🔗
    Now that we have two unknown constants, with a general solution of the form
    \begin{equation*} y = c_1 y_1 + c_2 y_2, \end{equation*}
    knowing just \(y(0)\) won’t be enough, as we’d have one equation with two unknowns! However, if we also know \(y'(0)\text{,}\) we get a system of two equations:
    \begin{align*} y(0) \amp= c_1 y_1(0) + c_2 y_2(0)\\ y'(0) \amp= c_1 y_1'(0) + c_2 y_2'(0) \end{align*}
    and we can uniquely solve for \(c_1\) and \(c_2\text{.}\)
    🔗

    Theorem 3.1.1. Existence and Uniqueness for Second-Order Linear ODEs.

    When solving \(ay'' + by' + cy = 0\text{,}\) there exists a unique solution given initial conditions \(y(0)\) and \(y'(0)\text{.}\)
    🔗
    🔗
    We actually saw this demonstrated earlier in the course in Example 1.2.2. When given acceleration \(a(t) = p''(t)\text{,}\) we needed to know both \(p(0)\) and \(v(0) = p'(0)\) to uniquely determine the position function. In general, we see this theme that a first-order ODE requires 1 initial condition, and a second-order ODE requires 2. This is a theme we’ll continue to see as we go.
    🔗

    Example 3.1.2. Solving an IVP: \(y'' - 4y' + 5y = 0\text{,}\) \(y(0) = 1\text{,}\) \(y'(0) = 5\).

    In Example 3.1.3, we already found that the general solution to \(y'' - 4y' + 5y = 0\) is:
    \begin{equation*} y = e^{2x}\left(c_1\cos(x) + c_2\sin(x)\right). \end{equation*}
    Now let’s use the initial conditions \(y(0) = 1\) and \(y'(0) = 5\) to find the unique solution.
    🔗
    Hint.
    First compute \(y'\text{.}\) Then plug in \(x = 0\) into both \(y\) and \(y'\) to set up the system of equations:
    \begin{align*} 1 \amp= y(0) = \ldots\\ 5 \amp= y'(0) = \ldots \end{align*}
    🔗
    🔗
    Solution.
    Starting with the general solution and computing \(y'\text{:}\)
    \begin{align*} y \amp= e^{2x}(c_1\cos(x) + c_2\sin(x))\\ y' \amp= 2e^{2x}(c_1\cos(x) + c_2\sin(x)) + e^{2x}(-c_1\sin(x) + c_2\cos(x))\\ \amp= e^{2x}\left((2c_1 + c_2)\cos(x) + (2c_2 - c_1)\sin(x)\right) \end{align*}
    Plugging in the initial conditions:
    \begin{align*} 1 = y(0) \amp= e^{0}(c_1\cos(0) + c_2\sin(0)) = c_1\\ 5 = y'(0) \amp= e^{0}((2c_1 + c_2)\cos(0) + (2c_2 - c_1)\sin(0)) = 2c_1 + c_2 \end{align*}
    From the system above, we get \(c_1 = 1\) and \(c_2 = 3\text{.}\)
    🔗
    Solution. Algebra for solving the system
    We have the system:
    \begin{align*} c_1 \amp= 1\\ 2c_1 + c_2 \amp= 5 \end{align*}
    The first equation gives \(c_1 = 1\) directly. Substituting into the second: \(2(1) + c_2 = 5\text{,}\) so \(c_2 = 3\text{.}\)
    🔗
    🔗
    Plugging in \(c_1\) and \(c_2\text{,}\) we find the unique solution to the IVP is:
    \begin{equation*} y = e^{2x}\left(\cos(x) + 3\sin(x)\right). \end{equation*}
    🔗
    🔗
    🔗

    Key Takeaways.

    • Two initial conditions: A second-order ODE needs both \(y(0)\) and \(y'(0)\) to uniquely determine a solution, one for each unknown constant \(c_1\) and \(c_2\text{.}\)
      🔗
      🔗
    • Process: Find the general solution, compute \(y'\text{,}\) plug in the initial conditions to get a system of two equations, solve for \(c_1\) and \(c_2\text{.}\)
